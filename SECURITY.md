# Security Policy

SquadUp runs in production at [squadup.in](https://squadup.in), so security
reports are taken seriously.

## Reporting a vulnerability

**Do not open a public issue.** Report it privately through GitHub instead:
go to the repository's **Security** tab and choose **Report a vulnerability**.

Please include:

- what the issue is and where it lives (file, endpoint or page)
- steps to reproduce it, or a proof of concept
- the impact you think it has

You should hear back within a few days. Once it is fixed, you will be credited
in the advisory unless you would rather stay anonymous.

## Scope

In scope: this repository's code and the services running at `squadup.in` and
its subdomains.

Out of scope: denial-of-service, spam, social engineering, and findings that
need a compromised device or account. Please don't access or change other
users' data while testing.
